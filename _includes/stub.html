{%- comment -%} Marker for a page whose content has not been migrated yet. It renders nothing (the visible "Stub page" notice was removed on request); the include line in a page is kept only so unmigrated pages can still be found with: grep -rl "include stub.html" --include=*.md . Remove the include line from a page when its real content is in place. Parameters (informational): legacy (path on www.star.bnl.gov), note (free text). {%- endcomment -%}
