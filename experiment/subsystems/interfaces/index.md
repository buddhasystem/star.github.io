*Last updated June 1998.*

This is the homepage for the STAR Interfaces Subsytem. The latest STAR interface specifications are listed below. For older versions please refer to the [STAR interfaces archive](https://www.star.bnl.gov/public/interfaces/old_stuff/old_versions.html){:target="_blank" rel="noopener"}&nbsp;<span data-feather="external-link"></span>.

  The definition of the data structures and the mailbox based handshake of the shared memory interface between Trigger and DAQ.
